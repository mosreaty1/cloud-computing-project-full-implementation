# Quick Start Guide for Windows

Get the Cloud-Based Learning Platform running on Windows in under 10 minutes!

## 🪟 Windows Prerequisites

### Step 1: Install Required Software

**Download and install these in order:**

1. **Git for Windows**
   - Download: https://git-scm.com/download/win
   - Run installer → Use default settings
   - ✓ Check "Git Bash Here" option

2. **Docker Desktop for Windows**
   - Download: https://www.docker.com/products/docker-desktop/
   - Run installer as Administrator
   - ✓ Enable WSL 2 when prompted
   - Restart computer
   - Start Docker Desktop (wait for whale icon)

3. **AWS CLI**
   - Download: https://awscli.amazonaws.com/AWSCLIV2.msi
   - Run installer
   - Click through wizard

**Verify installations (in PowerShell):**
```powershell
git --version
docker --version
docker-compose --version
aws --version
```

## 🚀 Quick Start (Local Development)

### Step 1: Clone Repository

```powershell
# Open PowerShell
cd C:\
git clone <repository-url>
cd cloud-computing-project-full-implementation
```

### Step 2: Setup Environment

```powershell
# Run setup script
.\scripts\setup-local.ps1

# This will:
# - Check prerequisites
# - Create .env file
# - Generate secure secrets
# - Create directories
```

### Step 3: Configure API Keys

```powershell
# Edit .env file
notepad .env
```

**Add your keys:**
```ini
# Get from https://platform.openai.com/api-keys
OPENAI_API_KEY=sk-your-key-here

# Generated by setup script - copy from output
JWT_SECRET=your-generated-secret-here
DB_PASSWORD=your-generated-password-here
```

Save and close the file.

### Step 4: Start Services

```powershell
# Make sure Docker Desktop is running!
# Check system tray for whale icon

# Start all services
docker-compose up -d

# Wait 2-3 minutes for initialization
Start-Sleep -Seconds 120
```

### Step 5: Verify Everything Works

```powershell
# Check service health
.\scripts\health-check.ps1

# You should see all services as "✓ Healthy"
```

### Step 6: Test the API

```powershell
# Test Text-to-Speech
$body = @{
    text = "Hello from Windows"
    language = "en"
    user_id = "test-user"
} | ConvertTo-Json

$response = Invoke-RestMethod -Uri "http://localhost:8000/api/tts/synthesize" `
    -Method Post `
    -ContentType "application/json" `
    -Body $body

# Show response
$response

# You should see audio_id and download_url
```

## ☁️ Deploy to AWS (30 minutes)

### Prerequisites

1. **AWS Account**: Create at https://aws.amazon.com
2. **Install Terraform**:
   ```powershell
   # Using Chocolatey (run as Administrator)
   choco install terraform -y

   # OR download from: https://www.terraform.io/downloads
   ```

### Step 1: Configure AWS

```powershell
# Configure AWS credentials
aws configure

# Enter:
# AWS Access Key ID: [your-key]
# AWS Secret Access Key: [your-secret]
# Default region: us-east-1
# Default output format: json

# Verify
aws sts get-caller-identity
```

### Step 2: Prepare Terraform

```powershell
cd infrastructure\environments\dev

# Copy example
Copy-Item terraform.tfvars.example terraform.tfvars

# Edit with your values
notepad terraform.tfvars
```

**terraform.tfvars:**
```hcl
aws_region   = "us-east-1"
project_name = "learning-platform"
environment  = "dev"
vpc_cidr     = "10.0.0.0/16"

db_username = "dbadmin"
db_password = "YourSecurePassword123!"
```

### Step 3: Deploy Infrastructure

```powershell
# Initialize
terraform init

# Plan (review what will be created)
terraform plan

# Apply (creates AWS resources - takes 20-30 min)
terraform apply

# Type 'yes' when prompted
```

### Step 4: Build and Deploy Services

```powershell
# Go back to project root
cd ..\..\..

# Login to ECR and build images
.\scripts\build-and-push.ps1

# Deploy to Kubernetes/Swarm
.\scripts\deploy-services.ps1 -Environment dev
```

### Step 5: Verify AWS Deployment

```powershell
# Get load balancer URL
cd infrastructure\environments\dev
$ALB_DNS = terraform output -raw alb_dns_name
cd ..\..\..

# Check health
.\scripts\health-check.ps1 -AlbDns $ALB_DNS

# Test API
Invoke-RestMethod -Uri "http://$ALB_DNS/health"
```

## 🐛 Common Windows Issues

### Docker Not Running
```powershell
# Check if Docker is running
docker ps

# If error, start Docker Desktop from Start Menu
# Wait for whale icon in system tray
```

### Port Already in Use
```powershell
# Find process using port 8000
netstat -ano | findstr :8000

# Kill process (replace 1234 with actual PID)
taskkill /PID 1234 /F
```

### PowerShell Script Execution Error
```powershell
# Run as Administrator, then:
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser

# Try script again
```

### Docker Volume Permissions
```powershell
# In Docker Desktop settings:
# Settings → Resources → File Sharing
# Add your project folder: C:\cloud-computing-project-full-implementation
# Click Apply & Restart
```

### AWS CLI Not Found
```powershell
# Close and reopen PowerShell
# Or add to PATH:
$env:Path += ";C:\Program Files\Amazon\AWSCLIV2"
```

## 💡 Windows Tips

### Use PowerShell (Not CMD)
Always use PowerShell for better compatibility.

### File Paths Work Both Ways
```powershell
cd C:\project\folder      # Windows style
cd C:/project/folder      # Unix style (also works)
```

### Environment Variables
```powershell
# Set variable
$env:AWS_REGION = "us-east-1"

# View variable
echo $env:AWS_REGION
```

### Docker Desktop Settings
- **Resources**: Increase CPU/Memory if slow
- **General**: Enable "Use WSL 2 based engine"
- **File Sharing**: Add project folder
